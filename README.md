# TextTone Studio — NOIR & GOLD

A Python desktop application that analyzes the sentiment of English messages and recommends suitable emojis. Built using object-oriented programming principles.

## Features
- Positive, Neutral and Negative sentiment detection
- Sentiment scores and emoji recommendations
- SQLite history with search and deletion
- Mood Insights dashboard
- Black-and-gold Tkinter interface

## Installation
1. Install Python 3.10 or newer with Tkinter support.
2. Download or clone this repository.
3. Install NLTK: `python -m pip install nltk`
4. Run: `python TextTone_Studio.py`

The VADER lexicon downloads automatically if not already installed. Internet access may be required for the first run.

## Note
This is a desktop application, not a browser-based application. Saved data is stored locally on the user's computer.
